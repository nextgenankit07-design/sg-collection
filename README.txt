# Shyam Garments — Premium Men's Wear

A responsive single-page storefront starter for Shyam Garments.

## Run
Open `index.html` in a browser.

## Replace logo
In `index.html`, replace the `logo-placeholder` block with your real logo image when ready.

## Add real products
Edit the `products` array in `script.js`. Replace placeholder product cards/images with your actual product photos when available.
